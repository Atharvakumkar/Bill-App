# Invoice-Now


A complete offline-first Flutter mobile application for generating simple bills and invoices.

## Features
- Create, Edit, Delete Bills
- Add Multiple Items with automatic calculation
- Generate Professional A4 PDF Invoices
- Convert total amount to Indian currency words
- Share / Save / Print Invoices
- Offline Local Storage using Hive
- Completely ad-free, private, and localized

## Prerequisites
- Flutter SDK >= 3.2.0

## Getting Started

1. Get the dependencies:
   ```bash
   flutter pub get
   ```

2. Run the application:
   ```bash
   flutter run
   ```

## Note
Since this application relies on Hive for local storage, the Type Adapters have been written manually.
No need to run `build_runner`.
